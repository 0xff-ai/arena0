# @0xff-ai/arena0-linux-x64

The `arena0`, `arena0d`, and `cargo-arena0` prebuilt binaries for Linux on
x86-64 with glibc 2.35 or newer. Alpine Linux is not supported by this package.
Installed automatically as an optional dependency of
[`@0xff-ai/arena0`](https://www.npmjs.com/package/@0xff-ai/arena0); do not
depend on it directly.
