# Security policy

arena0 0.1.x is pre-1.0 software and has not had an independent security audit.
Only the latest released version receives security fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not include
private keys, live invite tokens, real receipts, or exploit details in a public
issue. If private reporting is not available, open a public issue that asks the
maintainers for a private contact channel but contains no sensitive details.

Include the affected version or commit, the impact, the conditions needed to
reproduce it, and a minimal test or trace when it is safe to share one.

The maintainers will confirm receipt, assess severity, and coordinate a fix and
release before public disclosure.
